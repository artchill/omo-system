# 名單狀態

名單會依序經過下列狀態。狀態變更與 Close 一律由人員手動操作。

| 狀態 | 意思 |
| --- | --- |
| 待聯繫 | 新進名單，尚未有人聯繫 |
| 聯繫不上 | 已嘗試聯繫但沒有回應 |
| 已接觸待追蹤 | 已聯繫到對方，需要後續追蹤 |
| 接觸-待追蹤(消失) | 聯繫過一次後就沒有回應 |
| 諮詢-待追蹤(消失) | 已諮詢，之後沒有回應 |
| 諮詢-待追蹤(考慮中) | 已諮詢，對方正在考慮 |
| 諮詢中 | 諮詢進行中 |
| 暫緩 | 暫時擱置 |
| Won(名單成交) | 名單已轉為成交 |

Close 狀態代表名單結束：無效名單、聯繫不上、無意願、賣不動、撞單。已 Close 的名單可以重新開啟。
