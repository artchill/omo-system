# Lead statuses

A lead moves through these statuses. Status changes and Close are always done manually.

| Status | Meaning |
| --- | --- |
| Pending contact | New lead, nobody has reached out yet |
| Unreachable | Tried to contact, no answer |
| Contacted, to follow up | Reached the person, follow-up needed |
| Contacted, gone quiet | Reached once, then no response |
| Consulted, gone quiet | Had a consultation, then no response |
| Consulted, considering | Had a consultation, the person is deciding |
| In consultation | Consultation in progress |
| On hold | Paused for now |
| Won | Lead became a deal |

Closed statuses end the lead: invalid lead, unreachable, not interested, not converting, duplicate lead. A closed lead can be reopened.
